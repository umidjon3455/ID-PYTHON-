# 🧠 Python `id()` Mechanics & Memory Management

A comprehensive exploration of object memory addresses in Python using the built-in `id()` function. This repository covers everything from basic variable references to advanced CPython internals, memory reallocation, and custom object re-instantiation.

---

## 📌 Features & Topics Covered

- 🔹 **Basic `id()` Usage:** Inspecting object memory locations in standard data types.
- 🔹 **Mutable vs. Immutable Mechanics:** Observing how `id()` behaves when modifying `int`, `list`, `dict`, and `tuple`.
- 🔹 **Custom Objects & Memory:** Keeping fixed object IDs via custom classes and reference passing.
- 🔹 **CPython Memory Internals (`ctypes`):** Low-level analysis of `PyObject` C-structures and memory management.
- 🔹 **Advanced Metaprogramming:** Forcing identity shifts using Python Descriptors and Metaclasses.
